# 이중 언어 주석 규칙 / 二言語コメントルール

이 문서는 코드에서 한국어/일본어 이중 언어 주석 작성 규칙을 정의합니다.
このドキュメントはコードで韓国語/日本語二言語コメント記述ルールを定義します。

---

## 기본 형식 / 基本形式

한국어 주석 바로 아래에 일본어 번역을 작성합니다.
韓国語コメントのすぐ下に日本語翻訳を記述します。

```typescript
// 사용자 인증을 처리하는 함수
// ユーザー認証を処理する関数
async function handleAuth(): Promise<void> {
  // 토큰 유효성 검증
  // トークン有効性検証
  const isValid = await validateToken(token);

  // ...
}
```

---

## 일본어 작성 기준 / 日本語記述基準

### 레벨 / レベル

**비즈니스 레벨 (N1~비즈니스)** 수준의 자연스러운 일본어를 사용합니다.
**ビジネスレベル（N1~ビジネス）**水準の自然な日本語を使用します。

### 원칙 / 原則

| 원칙 / 原則 | 설명 / 説明 |
|------------|-----------|
| 직역 금지 | 한국어를 그대로 번역하지 않음 |
| 의역 권장 | 일본어로 자연스러운 표현 사용 |
| 어색함 금지 | 일본인이 읽었을 때 어색하지 않도록 |

### 예시 / 例

```typescript
// ❌ 잘못된 예 (직역) / 悪い例（直訳）
// 사용자를 가져오는 함수입니다
// ユーザーを持ってくる関数です  // ← 어색함

// ✅ 올바른 예 (의역) / 良い例（意訳）
// 사용자 정보를 조회하는 함수
// ユーザー情報を取得する関数
```

## 적용 범위 / 適用範囲

### 필수 적용 / 必須適用

다음 항목에는 반드시 이중 언어 주석을 작성합니다.
以下の項目には必ず二言語コメントを記述します。

1. **함수/클래스 설명** / 関数/クラス説明
   ```typescript
   // 사용자 세션을 관리하는 클래스
   // ユーザーセッションを管理するクラス
   class SessionManager {
     // ...
   }
   ```

2. **복잡한 로직 설명** / 複雑なロジック説明
   ```typescript
   // 재시도 로직: 최대 3회까지 시도, 지수 백오프 적용
   // リトライロジック: 最大3回まで試行、指数バックオフ適用
   for (let i = 0; i < MAX_RETRIES; i++) {
     // ...
   }
   ```

3. **CDK 리소스 선택 근거** / CDKリソース選択根拠
   ```typescript
   // ALB 선택 이유:
   // - L7 로드밸런싱으로 HTTP 헤더 분석 가능
   // - 경로 기반 라우팅 지원
   //
   // ALB選択理由:
   // - L7ロードバランシングでHTTPヘッダー分析可能
   // - パスベースルーティング対応
   new elbv2.ApplicationLoadBalancer(this, 'ALB', { ... });
   ```

4. **비용 관련 주석** / コスト関連コメント
   ```typescript
   // ⚠️ 비용 주의: NAT Gateway는 FreeTier에 포함되지 않음 (~$30-45/월)
   // ⚠️ コスト注意: NAT GatewayはFreeTierに含まれない（~$30-45/月）
   ```

5. **보안 경고** / セキュリティ警告
   ```typescript
   // TODO: 프로덕션에서는 IP 제한 필요
   // TODO: 本番環境ではIP制限が必要
   ```

### 선택 적용 / 選択適用

다음 항목은 필요에 따라 작성합니다.
以下の項目は必要に応じて記述します。

- 간단한 변수 선언
- 자명한 한 줄 로직
- 테스트 코드의 describe/it 블록

## 주석 스타일 / コメントスタイル

### 한 줄 주석 / 1行コメント

```typescript
// 인증 토큰 검증
// 認証トークン検証
const isValid = validateToken(token);
```

### 여러 줄 주석 / 複数行コメント

```typescript
// CloudFront 설정:
// - 기본 Origin: ALB (동적 콘텐츠)
// - 에러 Origin: S3 (정적 에러 페이지)
// - 캐싱 정책: 정적 에셋만 캐싱
//
// CloudFront設定:
// - デフォルトOrigin: ALB（動的コンテンツ）
// - エラーOrigin: S3（静的エラーページ）
// - キャッシュポリシー: 静的アセットのみキャッシュ
```

### JSDoc 스타일 / JSDocスタイル

```typescript
/**
 * 사용자 인증을 처리하는 함수
 * ユーザー認証を処理する関数
 *
 * @param token - JWT 토큰 / JWTトークン
 * @returns 인증 결과 / 認証結果
 */
async function handleAuth(token: string): Promise<AuthResult> {
  // ...
}
```

## 기술 용어 처리 / 技術用語処理

### 그대로 사용 / そのまま使用

일반적인 기술 용어는 영어 그대로 사용합니다.
一般的な技術用語は英語そのまま使用します。

```typescript
// API 엔드포인트 설정
// APIエンドポイント設定
```

### 번역 가능한 용어 / 翻訳可能な用語

| 한국어 | 일본어 | 영어 |
|--------|--------|------|
| 인증 | 認証 | Authentication |
| 권한 | 権限 | Authorization |
| 배포 | デプロイ | Deployment |
| 응답 | レスポンス | Response |
| 요청 | リクエスト | Request |
| 설정 | 設定 | Configuration |
| 환경 | 環境 | Environment |

## 랜딩 페이지 콘텐츠 / ランディングページコンテンツ

랜딩 페이지의 실제 콘텐츠(사용자에게 보이는 텍스트)는 **일본어만** 사용합니다.
ランディングページの実際のコンテンツ（ユーザーに見えるテキスト）は**日本語のみ**使用します。

```tsx
// Hero 섹션 컴포넌트
// Heroセクションコンポーネント
export function HeroSection() {
  return (
    <section>
      {/* 일본어 콘텐츠 / 日本語コンテンツ */}
      <h1>あなたのキャリアを、次のステージへ</h1>
      <p>私たちと一緒に、新しい可能性を見つけましょう</p>
    </section>
  );
}
```
